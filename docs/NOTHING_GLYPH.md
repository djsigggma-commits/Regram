# Nothing Phone (1): Glyph Interface

В настройках re:gram → «Другое» → **Nothing Glyph** включите **Glyph Interface**.
Интеграция по умолчанию выключена. Раздел виден на устройствах Nothing.

Phone (1) (модель `A063`, SDK `DEVICE_20111`) использует все пять групп
подсветки A–E, включая 15 каналов SDK:

- вспышка при входящих сообщениях (заглушённые чаты исключены);
- «дыхание» при входящем звонке и записи голосового сообщения;
- предпросмотр и опция вспышек сообщений только при выключенном экране.

Если запись или звонок начались до подключения системного Glyph-сервиса,
анимация запускается после подключения. При выключении интеграции подсветка
гасится, сессия закрывается. Glyph Matrix для Phone (1) не используется.

## Условия работы

Нужна прошивка Nothing OS с системным сервисом, совместимым с Glyph SDK.
Для распространяемой сборки задайте `GLYPH_API_KEY` в `local.properties`
или окружении: ключ выдаёт Nothing для пакета приложения. Значение `test`
в сборке — отладочное, оно не гарантирует работу на обычном устройстве.
Настройки системы также должны разрешать работу Glyph Interface.

## Проверка на телефоне

1. Включить интеграцию и нажать «Предпросмотр»: проверить все зоны A–E.
2. Получить сообщение из незаглушённого чата; повторить с заглушённым чатом.
3. Проверить опцию выключенного экрана.
4. Начать/остановить запись голосового; принять/отклонить входящий звонок.
5. Выключить интеграцию во время анимации: зоны должны погаснуть.

Регрессии: `python3 -m pytest -q tests/test_nothing_phone1_glyph.py`.
Тест SDK проверяет определение A063 и кадр всех 15 каналов; физическую
подсветку и доступ по API-ключу необходимо проверять на устройстве.
