## Функции из пользовательского списка 12.10.5

- Добавлено: просмотр локально сохранённой переписки с ИИ на экране настроек (`AiSettingsActivity`), с RU/EN-строками; история не отправляется в сеть при просмотре. Пустой/состоящий только из пробелов ответ модели (включая поток без содержимого) теперь возвращает ошибку и не сохраняется в историю (`Client.notifyResponse`). Для отсутствия ошибки при отправке ответов этому порту всё ещё нужны проверки на устройстве.
- По декомпилированному `AndroidUtilities.defaultUrlScheme` из APK добавлена схема `https://` для ссылок без протокола; для обычных числовых IPv4-адресов, где часто нет TLS, сохранён `http://`. Применено в обработке ссылок, ссылок из списка общих ссылок и контактных карточек (`AndroidUtilities`, `SharedLinkCell`, `PhonebookShareAlert`).
- Исправлена повторная попытка загрузки упавшего плагина после сканирования неизменённого файла: `PluginsController.rescanPlugins` теперь оставляет `loadError` и runtime-состояние в прежнем объекте; явная перезагрузка и смена файла по-прежнему позволяют повторить попытку. Исправлен режим планшета по образцу `AndroidUtilities` из APK: принудительный режим проверяется независимо от кэшированного значения для ориентации, учитывается `forceDisableTabletMode`, при смене режима из настроек сбрасывается кэш. Поведение после вращения устройства требует ручной проверки.
- Исправлена гонка инициализации пользовательских иконок: `IconPackManager` больше не помечает паки загруженными до чтения настроек и файлов. Если Android-контекст ещё не готов, загрузка повторится при следующем запросе. После общего сброса настроек кэш иконок теперь перечитывается.
