# Запрошенные плагины (проверка перед переносом)

Большинство плагинов из `~/Загрузки/Telegram Desktop` не запускались; для `exitFy_v2` и `Custom Profile (3)` сделаны **явные исключения** по запросу: закрытые DEX/runtime включены в APK. Они не исполняются при сборке и по умолчанию не запускаются. Четыре функции других плагинов перенесены в проверяемый Java-код (с ограничениями ниже), две функции визуальной подмены исходящих сообщений пока **не реализованы**. Существующий менеджер сторонних плагинов остаётся доступным.

| Плагин | Результат осмотра / ограничение |
|---|---|
| `plugstonav (4)` | Встроена дополнительная кнопка «Плагины» в нижнюю панель `MainTabsActivity`, открывающая штатный менеджер. Без DEX; это пункт перехода, не отдельная страница пейджера. |
| `mention_avatarsDEX` | Перенесено основное отображение аватара для **локально известных** пользователей/каналов на месте символа `@` в текстовых сообщениях. Используется существующий `AvatarSpan`; DEX не включён. Если профиль не загружен, исходный `@` остаётся. Переключатель находится в дополнительных настройках re:gram (по умолчанию включён). Настройки расположения и размера из плагина пока не перенесены. |
| `channel_autoread` | В меню супергруппы добавлен переключатель для каждого аккаунта/обсуждения; по умолчанию выключен. При новом авто-репосте канала, если это **единственное** непрочитанное сообщение в обсуждении и единственное сообщение этого чата в пакете уведомлений, он помечается прочитанным, а уведомление о нём убирается. При других непрочитанных сообщениях ничего не делается, чтобы не прочитать комментарии. Ручные пересылки и сообщения от анонимных администраторов не подходят под фильтр. |
| `online_stalker` | Добавлен пункт «Недавно в сети» в меню чатов. Список диалогов сортируется только по известным клиенту статусам, обновляется при событиях статуса и учитывает текущий аккаунт. Сервер не раскрывает скрытое время посещения. |
| `exitFy_v2` | В разделе exitFy можно **по отдельному подтверждению** активировать полную версию 4.2 из `assets/regram/exitFy_v2.py` (SHA-256 `c073c4c6ac6915c36675d7f1eab6cc6e8e8d9e36af0d7fbc352968039c1438a6`). Контроллер проверяет хэш и размер перед установкой; наличие другой установки не перезаписывается. Доступен только для Android 10+ arm64, использует существующий Python/DEX/JNI движок и требует уровня TRUSTED; это **встроенная поставка исходного плагина, а не Java-порт**. Установка включает движок плагинов, предупреждение сообщает о рисках. Отдельно доступен `exitFy Lite` — импорт только штатных Telegram-прокси без загрузки DEX. Не проверено на устройстве. |
| `Custom Profile (3)` | В дополнительных настройках re:gram появился экран Custom Profile с **постоянно видимым создателем @roflplugins** и переходом в его канал. По явному согласию устанавливается встроенный `custom_profile.py` 1.9 (SHA-256 `466b66b99475f12845828eb9a7c48fd3c21269933fc8354b5e458be580c5314f`), проверяется хэш/размер, существующая установка не перезаписывается. В собственные настройки плагина добавлена строка «Создатель / Creator: @roflplugins» как при рабочем ядре, так и при ошибке загрузки. Закрытый DEX **побайтно не изменён** (SHA-256 `47d4f4d2ef2006b97d6762babc59aed239465aeeabbd1ee4c68090f2c1466206`): сохранён оригинальный протокол и адрес `https://customprofile.pixivdl.net:23344/cpb`. Для запуска нужны полный доступ TRUSTED и работающий Python-движок; серверное поведение на устройстве не проверено и зависит от стороннего сервера. |
| `mymsgasothers` | Хук глобального `MessageObject.isOutOwner()` затрагивает не только отображение; нужен безопасный перенос только в UI чата, не затрагивающий отправку/прочтение. |
| `allleft` | Меняет `message.messageOwner.out` и кэш `isOutOwnerCached` на самих сообщениях; возможны ошибочные статусы и побочные эффекты за пределами отрисовки. Нельзя встраивать без переработки. |

Кроме согласованных исключений для exitFy и Custom Profile, не копировать сторонние `.plugin` в ресурсы приложения, не выполнять их на машине сборки и не запускать DEX вслепую. Полное соответствие всем шести остальным плагинам не достигнуто: два изменяют семантику исходящих сообщений; их безопасная реализация требует отдельного UI-only пути. Нужны проверки на устройстве, в особенности поведения уведомлений/прочтения, отображения упоминаний и нескольких аккаунтов. Полный exitFy на устройстве не тестировался; исходный закрытый runtime имеет доступ к процессу Telegram и потенциально к аккаунту. Остальные плагины через менеджер устанавливаются на риск пользователя.
