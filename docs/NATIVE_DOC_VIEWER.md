# Встроенный Doc Viewer

Нативный перенос `doc_viewer.plugin` **2.0.0** от **Daxo-Developer / @Daxo_OS**.
Исходник: `/home/atb/Загрузки/Telegram Desktop/doc_viewer.plugin`.
SHA-256: `93a610c5b8394e8697af412e61d263ae04e09c98c7574261af7ddff371353232`.
В файле нет закрытого DEX/runtime; явная лицензия и ссылка на исходный репозиторий не указаны.
Исходный плагин не запускался и не включён в ресурсы APK.

Всё реализовано в Java непосредственно в клиенте: **без хуков, BasePlugin, Python,
загрузки DEX и подмены методов**. Атрибуция автора постоянно доступна в настройках.

## Включение

**Настройки → openExtera → Other → Doc Viewer → Открывать документы внутри re:gram.**

Общий переключатель выключен по умолчанию, чтобы не менять существующее поведение
без выбора пользователя. Группы форматов включены; можно отключить любую отдельно.
Настройки прежнего плагина не импортируются и не удаляются.
Не держите одновременно включённым исходный Doc Viewer: существующие обработчики
плагинов сохранены и могут перехватить файл раньше нативного просмотрщика.

Открывается уже скачанный локальный файл. Просмотрщик не скачивает документы,
не передаёт их серверу и не собирает содержимое сообщений.
Неизвестные, отключённые и бинарные файлы с неподходящим текстовым расширением
остаются на прежнем пути открытия. Ошибки разбора/лимитов показываются внутри
просмотрщика; другое приложение выбирается **явно** из меню, кроме защищённых файлов.

## Форматы и возможности

| Группа | Реализация / ограничения |
|---|---|
| PDF | Android `PdfRenderer`, фоновые страницы, переход к странице, pinch/pan/double-tap, поворот, инверсия и вписывание. Пароль/повреждённый PDF может не открыться. OCR и поиск текста PDF не добавлены — их не было в исходном плагине. |
| Изображения файлом | `BitmapFactory`, уменьшение больших изображений, EXIF-поворот/зеркалирование, масштабирование, поворот и инверсия. Поддержка HEIF/AVIF/ICO и прочих кодеков зависит от Android; GIF показывается статическим кадром. |
| Текст / код | Постраничный текст, выделение/копирование, поиск с подсветкой, три шрифта, размер, перенос строк, тёмная/светлая/сепия. Это не IDE; код никогда не исполняется. |
| JSON / CSV / Jupyter | JSON с отступами, ограниченная таблица CSV/TSV, исходники ячеек и сохранённый текстовый вывод `.ipynb`. Ячейки, формулы и скрипты не запускаются. |
| DOCX / DOCM / DOTX / DOTM | Извлечение текста, заголовков, списков и таблиц; изображения — маркеры. Макросы и вложенные объекты игнорируются. |
| XLSX / XLSM / XLTX / XLTM | Листы по workbook relationships, shared/inline strings, булевы и сохранённые значения формул, даты с учётом 1900/1904. Формулы не вычисляются. |
| PPTX / PPTM / PPSX / POTX | Текст слайдов в порядке presentation relationships; без точного визуального воспроизведения и анимации. |
| ODF | Текст ODT/OTT, таблицы ODS/OTS, текст слайдов ODP/OTP; ограниченные повторения ячеек/строк. |
| RTF | Текст, Unicode, ANSI-кодировка, пропуск картинок/объектов/служебных групп и бинарных секций. Это не полный форматирующий RTF-движок. |
| EPUB / FB2 | Текст книг и порядок EPUB spine; без DRM, обложек, встроенных шрифтов и точной книжной вёрстки. |
| EML | Базовый MIME-предпросмотр: заголовки RFC 2047, plain/HTML body, base64/quoted-printable, имена вложений. Не почтовый клиент; не все MIME/RFC 2231 варианты реализованы. Вложения не извлекаются и не открываются. |
| Markdown / HTML / SVG | Изолированный офлайн WebView, поиск и исходный код. CommonMark с таблицами и зачёркиванием; HTML в Markdown экранируется. Внешние/локальные ресурсы и переходы заблокированы. Сложные/слишком большие Markdown и XML DTD отклоняются. |
| ZIP / JAR / AAR / TAR / TGZ / TBZ2 / TXZ | Только список имён и размеров, с отметкой шифрования ZIP. TAR с gzip/bzip2/xz поддерживается. Ничего не извлекается на диск. |

Бинарные Office `.doc/.xls/.ppt`, RAR/7z и другие незаявленные форматы не добавлены.
Office, книги и письма — **текстовый предпросмотр**, как в исходнике, не замена LibreOffice.
Внешний вид интерфейса не является точной копией плавающих кнопок плагина.

## Код и точки интеграции

`TMessagesProj/src/main/java/app/regram/documents/`:

- `DocumentFormat.java`: расширения/MIME и текстовая проверка первых 8 KiB.
- `DocumentText.java`: кодировки, UTF-16-совместимые страницы, XML/RTF, извлечение HTML-текста,
  общий расчёт ограниченного размера PDF bitmap.
- `DocumentReader.java`: Office, книги, текст, таблицы, блокнот и архивы.
- `DocumentMail.java`: ограниченный MIME parser.
- `DocumentWeb.java`: CommonMark и офлайн markup / CSP.
- `DocumentImageView.java`: настоящий Android View с жестами и matrix transform,
  без создания дубликата bitmap при повороте.
- `DocumentViewerDialog.java`: просмотр, поиск/настройки, внешний chooser, фоновые задания,
  ограничение битмапов и владение PDF/FD.
- `NativeDocViewer.java`: прямое открытие, жизненный цикл и отдельные настройки/позиции.

Экран: `app/regram/settings/NativeDocumentSettingsActivity.java`.
Строки: `values/regram_documents.xml` и `values-ru/regram_documents.xml`.

Прямые вызовы добавлены в штатные `AndroidUtilities.openDocument/openForView`.
Существующий `FilesControllerJava.dispatchOpenFile`, просмотр `.attheme`, импорт `.extera`
и путь установки APK сохранены; эти специальные расширения не перехватываются.
Файлы `MessageObject` разрешаются через **message.currentAccount**, а не выбранный
в данный момент аккаунт. Позиции зависят от аккаунта, формата, canonical path, размера
и времени изменения файла; сохраняется не более 200 записей, ключи — SHA-256.
При смене файла прежняя страница не навязывается новому содержимому.

### Зависимости

Используются уже существующие Android/AndroidX Exif, CommonMark (из Markwon), `org.json`
и Commons Text. Добавлены **Commons Compress 1.28.0** (Apache-2.0) и **XZ for Java 1.10**
для TAR/bzip2/xz. Это обычные библиотеки Java, не плагиновые DEX или скачиваемый runtime.

`zstd-jni` **не добавлен**. Для ZIP задана отвергающая Zstandard factory; части документов
разрешены только STORED/DEFLATED, проверяется CRC. Метаданные ZIP можно перечислять
без декодирования его файлов. В ProGuard подавлено только сообщение об отсутствующем
опциональном `com.github.luben.zstd.ZstdInputStream`, не вся библиотека.

## Защита и жизненный цикл

- Нет `eval/exec`, JavaScript bridges, выполнения макросов и скачивания ресурсов.
- WebView: JavaScript/file/content access/DOM storage/geolocation/multiple windows
  отключены, network loads и оба варианта navigation/resource callback заблокированы.
  Download listener ничего не запускает, permission requests отклоняются.
  CSP запрещает scripts/connect/frames/forms/base URL; изображения допускаются только
  как inline data, стили — inline. Нажатие ссылки не запускает другой клиент/браузер.
  При падении WebView renderer окно остаётся с ошибкой, view уничтожается.
- XML проверяется **после декодирования**, включая UTF-16: DTD и entity declarations
  отклоняются; внешний resolver всегда отвергает запрос. Есть глубина/число узлов,
  ограничения атрибутов и суммарного текста.
- Архивы не распаковываются. `../` в списке не создаёт файлов; external relationships
  и выход ссылок за корень EPUB/Office package запрещены.
- Для текстов — до 12 MiB исходных байтов с явной отметкой обрезки; HTML/Markdown/SVG —
  до 4 MiB. Часть XML/ZIP — до 12 MiB, суммарное чтение ZIP и расширение TAR — до 64 MiB,
  контейнер — до 128 MiB. XML: до 100000 узлов и глубины 64. Markdown: до 100000 строк/
  узлов, глубина 64 и до 65536 символов строки. Эти пределы не гарантируют безопасность
  от всех багов сторонних/платформенных декодеров.
- Таблицы: до 3000 строк / 60 столбцов; повтор ODF строк ограничен 20. Архивный список —
  до 20000 записей. Поиск — до 5000 совпадений / 1500 обычных подсветок страницы;
  активное совпадение подсвечивается отдельно. Копирование — до 900000 символов.
- PDF bitmap: до 3000000 пикселей и 4096 по стороне. Изображения уменьшаются до этих
  пределов. Нет тяжёлого предрендера/кэша трёх страниц и UI-thread render fallback
  из исходного плагина. Длинный нативный render не гарантируется прервать, но UI
  не ждёт mutex и не закрывает PDF одновременно с render.
- Все PDF операции и закрытие renderer/descriptor выполняет **один** background owner.
  При закрытии отменяются задания, устаревшие bitmap освобождаются, WebView и дочерние
  диалоги уничтожаются. Descriptor закрывается в `finally`, даже при ошибке renderer.close.
- При уничтожении Activity и показе код-пароля окна документов закрываются.
  Новое открытие при блокировке запрещено; внутренний переход к исходнику тоже
  проверяет блокировку и главный переключатель.
- Учитывается `noforwards` сообщения/чата и переданный `restrict`. В нативном защищённом
  просмотре отключены выделение/копирование/передача/внешнее открытие; `FLAG_SECURE`
  применяется к документу и дочерним диалогам. Флаг secure основного окна наследуется.
  Поведение внешнего legacy-пути и плагинов не переписывается: существующие сторонние
  плагины могут иметь собственные правила.
- Keep-screen-on принадлежит окну документа, не меняет флаги Activity постоянно.
  История позиций/настройки хранятся в private preferences; содержимое документа
  не сохраняется отдельно. Clipboard и внешний chooser используются только по
  явной команде пользователя и недоступны защищённому нативному просмотру.
