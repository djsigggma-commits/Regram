# re:gram 1.1.6.2 — удаление встроенного ExitFy

> **Не устанавливать этот APK.** После выпуска обнаружен startup-crash на Pixel 8 / Android 17: устаревший native-кеш зарегистрировал отсутствующий Java-метод `native_setDeviceMetadata`. Старые проверки не проверяли соответствие TgNet-регистраций внутри `.so`. Исправление и новый APK описаны в [BUILD_RELEASE_1.1.6.3.md](BUILD_RELEASE_1.1.6.3.md).

## Изменения

По запросу полностью удалены из исходников приложения:

- `ExitFyLite.java`, `ExitFyLiteActivity.java`, `BundledExitFy.java`;
- `assets/regram/exitFy_v2.py`, включая упакованные внутри DEX и native runtime;
- 22 строки интерфейса в английских и русских ресурсах;
- тесты удалённых функций и требование включать этот плагин в APK.

Добавлена проверка отсутствия удалённого runtime в исходниках, assets и ресурсах. Общие проверки изоляции файлов плагинов сохранены с нейтральным тестовым идентификатором. Обновлена текущая документация встроенных плагинов; исторические отчёты описывают старые сборки.

Штатные прокси Telegram, менеджер сторонних плагинов и Custom Profile сохранены. Обновление APK **не удаляет ранее установленный пользователем плагин из данных приложения**: если ExitFy уже установлен, его следует отключить/удалить через менеджер плагинов. Автоматической очистки пользовательских файлов нет.

Версия повышена с 1.1.6.1 (1010601) до **1.1.6.2 (1010602)**.
