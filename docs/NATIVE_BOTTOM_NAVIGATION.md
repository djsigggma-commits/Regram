# Нативные Folders Below и Plugins Tab (1.0.7)

Функции встроены в Java-код, без Xposed-хуков, рефлексии и загрузки DEX этих плагинов. Они включены постоянно; отдельные плагины `folders_below` и `plugstonav` необходимо отключить, чтобы их хуки не дублировали встроенную реализацию.

## Папки снизу

`org/telegram/ui/DialogsActivity.java`:

- Существующий `FilterTabsView` расположен над нижней навигацией, либо над системным нижним отступом при выключенной навигации.
- Высота видимых папок резервируется снизу списка, а не в заголовке; поиск, истории и верхние панели остаются сверху.
- Кнопка создания чата и область нижнего размытия учитывают папки.
- Позиция папок обновляется при анимации скрытия плавающей нижней панели.
- Сохраняются существующие механизмы выбора, редактирования, счётчиков и свайпов папок.

Логика сопоставлена с Java-исходником, указанным в `folders_below.plugin`:
https://github.com/Hazzz895/ExteraPluginsAssets/blob/main/bottomfolders/dex/src/main/java/com/pessdes/bottomfolders/Main.java

## Вкладка плагинов

`org/telegram/ui/MainTabsActivity.java`, `org/telegram/ui/Components/glass/GlassTabView.java`, `app/regram/plugins/ui/PluginsActivity.java`:

- Последняя вкладка «Плагины» — настоящая страница ViewPager, а не открытие отдельного экрана по кнопке.
- Позиция учитывает скрытые контакты/профиль и замену контактов лентой.
- Есть обычная/заполненная иконки, выделение при тапе и свайпе, повторный тап прокручивает список вверх.
- Для встроенной страницы нет кнопки возврата; нижний отступ учитывает навигацию, системные inset-ы и мини-плеер.
- Обычный вход в плагины через настройки сохранён, с кнопкой возврата.
- Используется существующая локализованная строка `OpenExteraPlugins`.

Поведение сопоставлено с декомпилированным DEX из `plugstonav (7).plugin` версии 1.3.1. Сам DEX в клиент не добавлен.

## Проверка

`tests/test_native_bottom_navigation.py` проверяет исходные контракты размещения, отступов, интеграции ViewPager и отсутствие загрузки/хуков payload-ов. Проверка Java-компиляции выполняется полной release-сборкой. Отрисовка и жесты на Android требуют ручной проверки: обычная, компактная, iOS и Material 3 панели; скрытые вкладки; поиск; редактирование папок; скрытие панели при прокрутке; мини-плеер и смена аккаунта.
