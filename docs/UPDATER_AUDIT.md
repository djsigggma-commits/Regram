# Проверка обновлятора

## Исправления

- Выбор APK учитывает весь `Build.SUPPORTED_ABIS`, а не только первую архитектуру.
- APK `arm64-v8a` больше не используется как универсальный fallback на несовместимых устройствах. `x86_64` не принимается за `x86`; `armeabi-v7a` не выбирается на arm64-only устройстве.
- Перед передачей установщику загрузка проверяется на непустое содержимое и соответствие известным размерам HTTP-ответа и GitHub asset. Это покрывает в том числе усечённые ответы без `Content-Length`. При ошибке используется существующий путь удаления файла и уведомления об ошибке.
- Логика вынесена в `UpdateArtifact.java` для исполняемых JVM-тестов, без Android-заглушек.

## Проверки

В окружении с JDK 21 из `~/.gradle/jdks/jetbrains_s_r_o_-21-amd64-linux.2`:

- `python3 -m pytest tests -q`: **430 passed, 31 skipped, 27 subtests passed**.
- Gradle 9.7.1: `--offline :TMessagesProj:compileDebugJavaWithJavac`: **BUILD SUCCESSFUL**.

Пропущенные проверки требуют внешнего корпуса плагинов, архивов и отсутствующих отчётов. Успешная компиляция не означает сборку или проверку APK на устройстве. Размер файла не является криптографической проверкой содержимого; штатная проверка подписи пакета остаётся обязанностью Android installer. Существующие APK в `artifacts/` не обновлялись.

Это ограниченный аудит и исправление подтверждённых дефектов обновлятора, а не свидетельство отсутствия всех ошибок в клиенте, JNI или сторонних плагинах.
