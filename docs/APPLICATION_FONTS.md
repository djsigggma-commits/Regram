# Шрифты приложения и медиаредактора

Экран сделан по пользовательскому образцу «Шрифты»:

- **Настройки re:gram → Оформление → Шрифты**;
- тот же экран доступен из **Функционал re:gram → Шрифты**.

## Шрифт приложения

В строке «Шрифт приложения» можно выбрать **По умолчанию** или один из
импортированных шрифтов. Выбор глобальный, не привязан к аккаунту. Применяется
после перезапуска; экран предлагает штатную кнопку перезапуска приложения.
Без сохранённого выбора остаётся прежняя типографика, включая существующие
настройки системного шрифта/Pixel Google Sans.

Шрифт подключён к `AndroidUtilities.getTypeface`/`bold`, обычному тексту сообщений
и списка чатов в `Theme`, общим `SimpleTextView`, `AnimatedTextView` и `Text`,
а также обычным Android TextView/EditText в окнах приложения, диалогах,
нижних панелях и ActionBar popup menus. Наклон и вес сохраняются средствами
Android; на старых API возможен синтетический bold/italic.

Намеренные исключения: моноширинный код, декоративные/иконные/аватарные шрифты,
явные шрифты медиатекста, предпросмотры шрифтов, веб-содержимое и системные экраны.
Это не изменение Android-системы или шрифтов других приложений. Отдельные
специализированные custom-drawn компоненты, которые обходят общие paint/helpers,
могут сохранять свою типографику; визуальный аудит всех экранов не проводился.
Не обещается наличие каждого символа в импортированном шрифте — fallback зависит
от Android и самого файла.

Выбранный UI-шрифт — **снимок на время процесса**. Изменение настройки не меняет
уже существующие layout/StaticLayout/paint кэши в живом приложении; после
перезапуска все общие точки видят новый выбор. При удалении выбранного файла
следующий запуск использует стандартный шрифт. Отсутствующий/нечитаемый файл
не должен блокировать запуск: используется прежний стандартный путь.

## Импорт

Кнопка «Добавить шрифт» использует **Storage Access Framework / ACTION_OPEN_DOCUMENT**.
Новых разрешений широкого доступа к хранилищу нет. Копирование выполняется в
фоновой очереди, в приватную папку `files/regram_fonts`:

- TTF, OTF и TTC (первая гарнитура коллекции);
- не больше **20 МиБ на файл**, не больше **32 импортов**;
- поток ограничен по фактическому числу прочитанных байт, а не только по metadata;
- проверяются sfnt magic и загрузка через Android Typeface Builder (API 26+),
  на API 24–25 — Typeface.createFromFile с отклонением default fallback;
- незавершённый/невалидный импорт удаляет temp/destination; библиотека и UI-выбор
  при ошибке не меняются;
- внутреннее имя создаётся из UUID и не зависит от имени/пути файла пользователя;
- display name очищается и ограничивается 80 UTF-16 единицами;
- запись metadata сериализована, но долгий ввод-вывод не удерживает блокировку
  UI font cache; повторная проверка лимита выполняется перед commit;
- выбор приложения сохраняется синхронно до предлагаемого перезапуска.

Настройки: отдельный глобальный `SharedPreferences("regram_fonts")`: импортированные
UUID/имена, UI-выбор, флаг списка системных шрифтов, hidden-набор и порядок.
Данные приложения сохраняются при установке подписанного обновления поверх.
Внешний файл после успешного импорта для работы не нужен. Отдельная интеграция
библиотеки с экспортом настроек/внешним backup в этом изменении не добавлялась.

## Список медиаредактора

Показываются встроенные гарнитуры, импортированные файлы и, по переключателю,
поддерживаемые существующим Telegram медиаредактором системные семейства.
Это существующий curated список на Android 10+, не полный перечень каждого
системного Noto/font file. Существующая доступность системных семей остаётся
включённой по умолчанию; переключатель управляет списком, а не UI-шрифтом.

Название каждой гарнитуры отображается её реальным шрифтом. Есть обозначения
«Стандартный», «Импортированный», «Системный», ручка перетаскивания и глаз.
Скрытие и порядок применяются к `PaintTypeface.get()` — тому самому списку,
который читает инструмент текста. Кнопка «Сбросить порядок» сбрасывает только
порядок, не удаляет файлы и не снимает флаги скрытия.

`PaintTypeface.find(key)` ищет по **нефильтрованному** каталогу и импортам: скрытие
или выключение системного списка не подменяет гарнитуру уже сохранённого текста.
Удаление файла, в отличие от скрытия, может потребовать fallback в старых
сохранённых entities; перед удалением показано предупреждение. Если скрыть всё,
в редакторе остаётся стандартный Roboto, чтобы инструмент не получил пустой список.

Встроенные шрифты редактора загружаются непосредственно из assets и не становятся
копиями нового UI-шрифта. FontWindows исключает медиатекст/превью из подстановки.

## Работа с окнами

Нет reflection над приватными Typeface полями или изменения системного font map.
`FontWindows` устанавливает listener только при активном импортированном UI-шрифте.
Он обходит иерархию при layout, а не опрашивает её в frame callback; уже применённые
Typeface не переустанавливаются. Нет глобального списка с сильными ссылками на окна.
При detach listener снимается, при reattach/переносе floating ViewTreeObserver
восстанавливается без дубликатов. Меню с повторно используемым content view учтены.

## Проверки и ограничения

`tests/test_application_fonts.py` выполняет реальные:

- bounded copy: четыре поддерживаемых sfnt header, усечённый/невалидный вход,
  точный лимит 20 МиБ и превышение, обработка display name;
- UI policy: отсутствие контекста, default, снимок процесса, веса/italic,
  сохранение mono/serif/decorative, fallback при отсутствии файла, API 24 style path;
- catalog filtering/order: system flag, hidden entries, стабильный порядок,
  сброс и непустой fallback;
- проверяет SAF/background import, atomic metadata sequence, private UUID path,
  restart, drag, visibility, RU/EN строки и точки интеграции.

`tests/test_font_windows.py` исполняет реальные установку/listener/обход с doubles:
нет работы при default, нет повторных listeners, поздно добавленные TextView,
исключения code/preview/media, detach/reattach и перенос floating observer.

Host-тесты **не исполняют Android native font decoder** и не доказывают визуальное
покрытие всех экранов, кириллицу, метрики или скорость layout на устройстве.
ADB-устройств на сборочном хосте нет. Проверить физически: импорт нескольких TTF/OTF,
перезапуск/сброс, кириллицу и emoji fallback, диалоги, сообщения/список чатов,
набор текста, планшет/RTL/крупный шрифт, поведение медиаредактора и его старых drafts.
Функция включена в подписанный [релиз 13.1.1.1](BUILD_RELEASE_13.1.1.1.md).
Итоговый suite: 507 passed, 31 skipped, 27 subtests passed.
Логи релизной проверки: `reports/release-13.1.1.1/`.
