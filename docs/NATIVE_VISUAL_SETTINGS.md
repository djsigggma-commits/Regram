# Встроенные MonoColor UI и AllLeft (1.0.4)

Перенесена функциональность предоставленных плагинов **MonoColor UI 1.7** и **AllLeft 2.0.6**, автор **@limeplug**. Их встроенный DEX изучен, но не добавлен в клиент и не исполняется. Реализация — обычный Java-код клиента, без Xposed, рефлексии, Python и загрузки плагинов.

## Где включить

В 1.0.5 пункт переименован в **«MonoColor, AllLeft и упоминания»** и дополнен [аватарами упоминаний](NATIVE_MENTION_AVATARS.md). Ниже описаны исходные два режима выпуска 1.0.4.

**Настройки re:gram → Оформление → MonoColor UI и AllLeft.** Оба основных переключателя по умолчанию выключены. Перед включением отключите соответствующие исходные плагины: их собственные хуки могут конфликтовать со встроенной отрисовкой. Настройки плагинов не удаляются и автоматически не импортируются.

### MonoColor UI

- Цвет кнопки, акцент темы/Monet, шапка, ссылки, плавающая кнопка, исходящие пузыри либо свой цвет.
- Собственный цвет выбирается стандартной палитрой клиента; сохраняется непрозрачным.
- Градиент и отдельные переключатели аватаров/фото, историй/близких друзей/эфиров, имён, названий/последних сообщений в списке чатов, пользовательских цветов профилей.
- Оттенки имён адаптируются к читаемости в светлой/тёмной теме. Палитра и матричный фильтр кэшируются.
- `Theme.getColor` накладывает выбранные визуальные цвета, не переписывая карты/файлы темы. PeerColor читает визуальную палитру, не меняя исходные серверные массивы.
- Обычные и сложные градиенты AvatarDrawable используют новый режим непосредственно при рисовании.
- Фото окрашиваются на уровне ImageReceiver, без изменения пикселей и кэшированных файлов. Фильтр общей миниатюры восстанавливается после рисования; background-holder получает отдельный снимок состояния.

### AllLeft

- Сообщения рисуются слева; в личных чатах включается место под аватар и имя, как в группах.
- «Только личные чаты» включает и секретные чаты; группы/каналы в этом режиме не меняются.
- Есть переключатель отметок доставки/прочтения. Сохранены часы отправки и значок ошибки. Для секретных чатов учитывается состояние прочтения, даже при отрицательном ID сообщения.
- Избранное проверяется по аккаунту сообщения; рекламные сообщения, предпросмотры и quick replies исключены.
- Реальный `MessageObject.isOutOwner()` не изменён. Отдельный `isOutOwnerForLayout()` используется геометрией/отрисовкой, расчётом альбомов и анимациями. Настоящая принадлежность остаётся для сетевых операций, прав и определения автора, включая секретные чаты.
- Группировка подряд идущих сообщений продолжает проверять реальную принадлежность и отправителя. Кэш текстовой раскладки/альбомов учитывает переключение режима.

## Основные файлы

- `app/regram/appearance/MonoColor.java`
- `app/regram/chats/AllLeft.java`
- `app/regram/settings/NativeVisualSettingsActivity.java`
- `tw/nekomimi/nekogram/NekoConfig.java`: 12 сохраняемых параметров (10 bool и 2 int).
- Native call sites: Theme, PeerColor, AvatarDrawable, ImageReceiver, MessageObject, ChatMessageCell, ChatActivity и ChatListItemAnimator.
- Переводы: `res/values/regram_native_visual.xml`, `res/values-ru/regram_native_visual.xml`.

## Проверки

**259 passed, 31 skipped, 27 subtests passed.** Новые тесты исполняют реальные Java-методы политик с Android/API-заглушками: разные аккаунты, Избранное, секретные/личные/групповые чаты, отключение/включение режимов, источники цвета, градиент, читаемость и сохранение alpha матричного фильтра. Это не Android-инструментальные тесты и не доказательство отсутствия визуальных дефектов.
