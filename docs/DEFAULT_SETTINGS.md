# Настройки по умолчанию из экспорта 11 октября 2026

Портативный профиль хранится в
`TMessagesProj/src/main/assets/regram/default-settings.json`.

- На чистой установке он записывается до загрузки `SharedConfig`, `NekoConfig`
  и темы. Если уже есть настройки хотя бы в одном из четырёх разделов,
  существующие preferences не перезаписываются.
- Для `ConfigItem` профиль задаёт значения отсутствующих параметров и
  `defaultValue`, поэтому сброс настроек этих параметров использует тот же
  профиль. Сохранённые пользовательские значения имеют приоритет.
- Раскладка пилюль при сбросе берётся из профиля, а не из старой константы.
- Суффиксы экспорта `_float`/`_long` удаляются из реальных ключей, числа
  записываются с соответствующим типом SharedPreferences.

Основные значения: Monet Dark, трёхстрочный список чатов, стили переключателей
и слайдеров 2, радиусы аватаров 14 и секций 20, MD3-плеер/миниплеер,
пилюли `5,6,1,7`, сохранение удалённых сообщений и истории правок.
Остальные переносимые значения сохранены в JSON.

Monet доступен на Android 12+. На более старых версиях начальная тёмная тема —
Night, дневная — Blue, чтобы не ссылаться на отсутствующую тему.

## Что намеренно не переносится

- Персональные `userNameOverride_*` и `chatNameOverride_*`.
- Удалённая тема Evening Cucumber, путь `/data/user/0/com.exteraless.app/...`
  и сериализованные списки скачанных тем/акцентов.
- Времена обновлений, хэши удалённых тем, координаты автоматической ночной
  темы, счётчики подсказок и обслуживания медиа, служебные поколения миграций.
- Последняя открытая пилюля и состояние редактора паков иконок.

Нужные флаги миграции раскладки/заголовка/переводчика сохранены, чтобы первый
запуск не переинтерпретировал готовые настройки как старый формат.

Выбор паков иконок `hu,materialexpressiveicons` сохранён, но сами файлы паков
в экспорт JSON не входят и в исходниках отсутствуют. До установки этих паков
клиент использует встроенные иконки. Для точного воспроизведения внешнего вида
нужны сами паки, а не только экспорт настроек.

Проверки: `python3 -m pytest -q tests/test_bundled_settings_defaults.py`.
