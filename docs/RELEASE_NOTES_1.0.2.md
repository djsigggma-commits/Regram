# re:gram 1.0.2 — обновление основы

- Основа обновлена с exteraless 12.10.5-beta13.1 до **12.10.6-beta14** из предоставленного каталога.
- Telegram: `APP_VERSION_NAME=12.10.6`, `APP_VERSION_CODE=7112`.
- Версия re:gram: **1.0.2**, Android `versionCode=10002`; пакет остаётся `app.regram.android`.
- Перенесены изменения движка плагинов и модели разрешений, MD3-плеер, очистка tracking-параметров ссылок, выбор иконок, изменения настроек, оформления и исправления основы.
- Сохранены оформление re:gram, авторы и реквизиты, встроенные плагины, переносы из Inugram/Nagram XF, совместимость старых имён `app.exteraless.*`, собственный канал обновлений и проверки release-подписи.
- Настройки сохранения поиска и скрытия подсказок хэштегов остаются в разделе поиска чатов. Сортировка альбомов по размеру находится в новом подразделе медиа.
- Подмодули закреплены по gitlink-ревизиям тега `v12.10.6-beta14`; скрипт восстановления теперь включает форк Chaquopy.

## Проверки

- `python3 -m pytest tests -q`: **231 passed, 33 skipped, 27 subtests passed**. Пропуски относятся к недоступным внешним корпусам/подмодулям и условиям тестов; это не проверка APK.
- Проверена синтаксическая корректность Java/Kotlin (tree-sitter), Python (AST) и XML.
- При первоначальном обновлении сборка APK не выполнялась. Затем подготовлено отдельное окружение с существующими приватными настройками владельца и собран подписанный release APK для arm64-v8a; проверки и контрольная сумма: [BUILD_RELEASE_1.0.2.md](BUILD_RELEASE_1.0.2.md). Требования к выпуску: [RELEASE.md](RELEASE.md).
- Работа на устройстве, авторизация, push, плагины, плеер и миграция настроек требуют отдельной проверки. Для обновления установленного приложения необходим прежний ключ подписи.

Резервная копия дерева до переноса: `../Regram-before-beta14.tar.gz` (локальная, не часть проекта).
