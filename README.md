# re:gram

**re:gram 13.2.2** — неофициальный Android-клиент Telegram на базе **exteraless 13.2.2**, исходники обновлены до коммита **[`31a35e46`](https://github.com/exteraless/exteraless/commit/31a35e4683fb420ee782cdd32f36aea812bf756c)** из [Actions 43392419710](https://github.com/exteraless/exteraless/actions/runs/43392419710). [Отчёт о текущем обновлении](docs/BASE_43392419710.md), [предыдущая основа](docs/BASE_c83765c4.md). Сохранены отдельные возможности Inugram и Nagram XF. Пакет: `app.regram.android`. Это **частичная интеграция**, а не полная замена исходных проектов.

**Собран подписанный release APK 13.2.2 для arm64-v8a**: `artifacts/regram-v13.2.2(13020200)-release-arm64-v8a.apk` (82.7 MiB). [Отчёт, SHA-256 и проверки](docs/BUILD_RELEASE_13.2.2.md). Подпись совпадает с APK 13.1.1.1; проверены R8, JNI и новая `libtwidget.so`. **На устройстве не проверен.** Текущая версия — **`13.2.2`**, Android `versionCode=13020200`, Telegram layer **233**. Предыдущая локальная сборка: [13.1.1.1](docs/BUILD_RELEASE_13.1.1.1.md). [Правила нумерации](docs/VERSIONING.md). [Подписанный release APK 1.4.8.9 для arm64-v8a](docs/BUILD_RELEASE_1.4.8.9.md) содержит предыдущий снимок основы 13.1.1 (`4771c553`), [оптимизации без удаления функций](docs/PERFORMANCE_13.1.1.md) и [встроенный Telegram WebSocket-транспорт](docs/NATIVE_TELEGRAM_WEBSOCKET.md). APK пересобран с WS-пулом **4**, включёнными по умолчанию Cloudflare-маршрутами, названиями **«Обход блокировки» / «Использовать обход»** и без длинного описания под настройками; номер версии оставлен прежним. Проверены R8, упаковка, версия, подпись и JNI, включая WSS callbacks, класс пула и значения defaults непосредственно в DEX; сертификат совпадает с APK 1.4.8.8. Файл: `artifacts/regram-v1.4.8.9(1040809)-release-arm64-v8a.apk`. **На устройстве не проверен.**

> **Статус:** APK — релизный кандидат. Автоматические тесты и проверка подписи не заменяют тестирование на устройствах, включая Samsung. Не публикуйте APK как проверенный релиз до прохождения [сценариев проверки](docs/INTEGRATION.md#проверка-на-устройстве-после-успешной-сборки).

## Возможности

- В текущих исходниках «Встроенное оформление», «Быстрая настройка темы», **Termux Bridge, Doc Viewer, S Pen и «Создатели и источники»** собраны в **Настройки → Настройки re:gram → Функционал re:gram**. [Описание](docs/REGRAM_FEATURES_HUB.md). Раздел «MD3extra, компактная панель и чипсы папок» и его функции удалены, кроме папок-чипсов: они находятся во «Встроенное оформление → Папки-чипсы». Изменения включены в APK 1.4.5.

- Настройки re:gram распределены по разделам «Основные», «Оформление», «Чаты» и «Ещё»; поиск настроек доступен. «Создатели и источники» и реквизиты для поддержки разработки находятся в «Функционал re:gram».
- Темы, оформление, плагины и другие функции, унаследованные от exteraless; дополнительные настройки и исправления из Inugram и Nagram XF. Не все функции сторонних плагинов проверены на реальных устройствах.
- [Встроенные MonoColor UI и AllLeft](docs/NATIVE_VISUAL_SETTINGS.md): единый оттенок аватаров, историй, имён и списка чатов; сообщения слева с именами, аватарами и отметками доставки. Оба режима включаются в «Оформление → MonoColor, AllLeft и упоминания», без плагинов и хуков. [AllLeft обновлён до 2.0.11](docs/NATIVE_ALLLEFT.md); изменения включены в локальную сборку 1.3, device validation отсутствует.
- [Встроенные папки-чипсы (Chip Folders)](docs/NATIVE_PLUGIN_STYLES.md): формы, цвета, анимации, размеры и отступы; **Функционал re:gram → Встроенное оформление → Папки-чипсы**, по умолчанию выключены. Прежние настройки чипсов сохранены. MD3extra/Weex-палитра, импорт шрифтов, Expressive/FAB и Compact Bottom Nav удалены из исходников; штатные настройки оформления клиента остаются.
- [Встроенный Telegram WebSocket-транспорт](docs/NATIVE_TELEGRAM_WEBSOCKET.md): подключение tgnet через WSS напрямую к DC или по Cloudflare-маршрутам, без отдельного приложения, локального MTProxy-порта и фонового сервиса. «Функционал re:gram → Обход блокировки»; по умолчанию выключен, TCP-резерв разрешается отдельно, внешние прокси имеют приоритет. Экспериментально: включено в APK 1.4.8.9, состав DEX/JNI проверен; на устройстве и реальной сети ещё не проверено. Звонки, CDN и bootstrap не охватываются. В пересобранный APK 1.4.8.9 включён настоящий WS-пул (по умолчанию 4 на маршрут, варианты 0/2/4/8) и включены Cloudflare-маршруты по умолчанию; сохранённый выбор пользователя остаётся.
- [Встроенный S Pen](docs/NATIVE_SPEN.md): выделение текста кнопкой пера, двойное касание, выбор сообщений по фону и нажатие при наведении. Без хуков и плагина; openExtera → Other → S Pen, по умолчанию выключен. Включён в сборку 1.3; проверка на Samsung ещё не выполнена.
- [Встроенный Doc Viewer](docs/NATIVE_DOC_VIEWER.md): PDF/изображения, текстовый предпросмотр Office и книг, Markdown/HTML/SVG без сети, списки архивов. Без хуков и загрузки плагина; выключен по умолчанию, настройки в openExtera → Other → Doc Viewer. Включён в локальную сборку 1.3.
- [Встроенный Termux Bridge](docs/NATIVE_TERMUX_BRIDGE.md): localhost-мост, оверлеи/панели, Java RPC и ИИ без загрузки плагина и хуков. Сервер и выполнение кода выключены по умолчанию; настройки в openExtera → Other → Termux Bridge. Включён в локальную сборку 1.3.
- [Встроенные аватары упоминаний](docs/NATIVE_MENTION_AVATARS.md): аватары у @username и ссылок в сообщениях и подписях, расположение до/после/вместо @ (по MentionAvatars 1.1.3) и три размера, фильтры ботов и чатов. По умолчанию выключены; только известные текущему аккаунту пользователи/чаты, без хуков и изменения текста.
- Бейджи поддержавших разработку: `ids.txt` принимает строку вида `748121342 - tg://emoji?id=5296437331648096571 - разраб1`. Текст после второго тире отображается при нажатии на бейдж. Старые записи без текста работают как прежде.
- Обновление **13.2.2 / `31a35e46`**: HTML-виджеты с изолированным процессом, новый PiP, компактное оформление чатов, категории ленты, inline-конвертеры, пословная подсветка текстов песен, исправления плагинов и MTProto. Сохранены локальные возможности re:gram; [изменения и ограничения проверки](docs/BASE_43392419710.md).
- Предыдущее обновление `c83765c4`: постоянный значок загрузок в настройках навигации, исправления совместимости и ошибок callback плагинов, renderer круглых видео, безопасное удаление повреждённых Lottie только в каталогах Telegram, исправления перевода выделенного текста и плеера. Добавлено upstream-разрешение «Доступ ко всем файлам» (не выдаётся автоматически); отчёты Crashlytics с hook frames теперь включают признаки хуков и ID включённых плагинов. [Подробности и ограничения](docs/BASE_c83765c4.md).
- Основа 13.1.1: новые QR-экраны, аудиозапись и настройки круглых видео, приватность ботов (по умолчанию выключена), изменения плеера и совместимости плагинов. Last.fm и его фоновые web-запросы удалены upstream; карточка сохранённой музыки остаётся.
- Нумерация следует Telegram-основе: `APP_VERSION_NAME=13.2.2`, `REGRAM_VERSION=13.2.2` → Android `versionCode=13020200`. В настройках и окне обновлений: **`13.2.2`**, без base/legacy/commit suffix; историческая отметка `1.4.8.9` не менялась.

## Скачать и установить

Подписанные кандидаты могут быть размещены в [GitHub Releases](https://github.com/djsigggma-commits/Regram/releases), **если владелец проекта подтвердил их выпуск**. Выбирайте APK под архитектуру телефона (`arm64-v8a` для большинства современных устройств). Пакет не заменяет Telegram или другой клиент; для обновления уже установленного re:gram необходима **та же подпись** и больший `versionCode`. Перед установкой проверьте источник и контрольную сумму файла в описании выпуска.

## Подготовка сборки

Нужны Linux x86_64, JDK 21, Android SDK/NDK и CMake из Gradle-проекта, Python 3.11 для Chaquopy, Gradle 9.7.1, `rsync` и зависимости из скрипта проверки окружения. Исходники native-подмодулей восстановите через `./tools/restore_submodules.sh .` (требуется сеть). `tools/build.sh` переносит исходники в путь без двоеточия для Chaquopy.

```sh
python3 -m pytest tests -q
python3 tools/check_build_env.py
NATIVE_TARGET=arm64-v8a CHAQUOPY_BUILD_PYTHON=/path/to/python3.11 \
  ./tools/build.sh -Dorg.gradle.jvmargs=-Xmx10g :TMessagesProj:assembleDebug
```

Для рабочего APK требуются **свои** Telegram API ID/hash и Firebase-конфигурация пакета `app.regram.android`. Для подписанного релиза дополнительно нужен собственный release-keystore и пароли; **никогда не добавляйте их в git**. Заглушки (`REGRAM_COMPILE_CHECK=1`) годятся только для проверки компиляции. Подробные требования, команды и проверка готового APK: [docs/RELEASE.md](docs/RELEASE.md). Проверки не гарантируют работу входа, push, плагинов и карт на устройстве.

## Производительность и ограничения

[Оптимизация/debloat на основе 13.1.1](docs/PERFORMANCE_13.1.1.md): устранены копирование неизменной очереди, повторный поиск трека для каждой видимой строки, лишние gradient/ARGB/time-label allocations и regex parsing упоминаний; исправлено освобождение копий обложек профиля и разгружена общая очередь. Сохранены геометрический кэш чипсов и read-only аудит APK. Функции в этом проходе не удалялись. FPS/батарея на устройстве не измерялись.

Некоторые горячие пути оптимизированы без отключения функциональности; ресурсы и зависимости, которые разрешаются динамически (включая плагины), не удаляются вслепую. Без профиля с конкретного устройства невозможно обещать отсутствие лагов на всех моделях. Для отчёта приложите модель Samsung/Android, сценарий, logcat и системную трассировку. Технические заметки: [производительность](docs/PERFORMANCE.md), [архив разработки](docs/DEVELOPMENT_HISTORY.md).
